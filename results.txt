VALIDATION DESIGN
-----------------
The test set is chronological (2013-2014).
Hyperparameter selection uses five expanding, year-blocked validation
folds on the training period. Each validation fold contains a complete
year and trains only on earlier years.

Feature Set A:
  temp, do, ph, cond, bod, nitrate, fc, tc

Feature Set B:
  temp, do, ph, cond

INTERPRETATION
--------------
1. Set A produces very high scores because its input variables include
   the measurements used to construct the WQI target. This is mainly
   formula reconstruction, not independent water-quality measurement.
2. Set B is the practical field-measurement experiment. Its best
   regression model has RMSE 11.324 and R2 0.440.
3. The station-mean baseline (RMSE 7.930, R2 0.726) outperforms every
   Set B regression model. This limitation must be stated clearly.
4. Set A Gradient Boosting classification reaches 93.3% accuracy and
   0.930 macro-F1 in this reproducible run.
5. Scores from the earlier report differ slightly because the updated
   implementation uses year-blocked forward validation for hyperparameter
   selection. The chronological 2013-2014 test set is unchanged.
6. The dataset is not a station-held-out evaluation: the earlier analysis
   found that 99.8% of test-station records also occur in training.
   Generalisation to completely unseen stations is therefore unproven.
